## Опис проєкту

Це дипломний Flask-прототип інтелектуальної інформаційної системи для менеджера ритейлу. Система аналізує історичні продажі товарів, створює ознаки для машинного навчання, навчає модель прогнозування попиту, показує forecast у dashboard та формує рекомендації щодо закупівлі товарів.

## Мета

Автоматизувати частину процесів ритейлу, пов'язаних із прогнозуванням попиту, контролем залишків і плануванням закупівель.

## Основні можливості

- завантаження CSV-даних;
- аналіз історичних продажів;
- прогнозування попиту на товари;
- рекомендації закупівель;
- перегляд метрик MAE, RMSE, MAPE;
- авторизація менеджера;
- dashboard для захисту дипломної;
- REST API для інтеграції.

## Технології

- Python;

## Структура проєкту

```text
app/                 Flask-додаток, шаблони, стилі, авторизація
src/                 ML, preprocessing, прогнозування, рекомендації, SQLite
data/                Демонстраційний CSV-датасет
models/              Навчена модель і метрики
docs/                Документація для дипломної роботи
screenshots/         Місце для скріншотів системи
tests/               Базові тести API та ML-модулів
```

## Встановлення

Потрібен Python 3.12 або новіший. На Windows, якщо команда `python` не налаштована в PATH, використовуйте `py -3.12` або повний шлях до Python.

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

## Запуск локально

```bash
python src/generate_dataset.py
python src/train_model.py
python app/app.py
```

Після запуску відкрийте: `http://127.0.0.1:5000`

## Деплой

Проєкт підготовлений для Render або Railway:

- `Procfile` запускає Gunicorn;
- `render.yaml` описує web-сервіс;
- `runtime.txt` фіксує Python runtime;
- `PORT` читається із середовища.
