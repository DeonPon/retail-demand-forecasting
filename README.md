# Retail Demand Sense

Інтелектуальна система прогнозування попиту на товари для автоматизації процесів ритейлу.

## Тема кваліфікаційної роботи
«Розробка інтелектуальної системи прогнозування попиту на товари для автоматизації процесів ритейлу».

## Опис
Retail Demand Sense — Flask/Python дипломний проєкт, який аналізує історичні продажі товарів, формує ознаки для машинного навчання, порівнює кілька моделей, прогнозує майбутній попит і пояснює результат у web-інтерфейсі.

Система показує повний цикл роботи ML-прототипу: CSV-імпорт, очищення даних, feature engineering, навчання моделей, оцінка точності, побудова прогнозу та візуалізація результатів.

## Призначення
Проєкт призначений для підтримки аналітичних процесів у ритейлі:
- аналіз історичних продажів;
- прогнозування майбутнього попиту;
- оцінка динаміки продажів;
- врахування ціни, акцій, сезонності та календарних факторів;
- підтримка управлінських рішень щодо роздрібних операцій.

## Функціональність
- імпорт історичних продажів з CSV;
- збереження даних у SQLite;
- перегляд структури набору даних;
- побудова прогнозу на 7, 14 або 30 днів;
- графік історичних продажів і майбутнього прогнозу;
- коротка інтерпретація прогнозу;
- пояснення факторів впливу;
- оцінка якості моделі за MAE, RMSE, MAPE;
- порівняння RandomForestRegressor, GradientBoostingRegressor та ExtraTreesRegressor;
- REST API для перевірки стану, даних, прогнозу та метрик.

## Запуск

```bash
pip install -r requirements.txt
py app/app.py
```

```text
http://127.0.0.1:5000
```

## Структура CSV
Обов’язкові колонки:
- `date`
- `product_id`
- `product_name`
- `category`
- `sales_quantity`
- `price`
- `stock_quantity`
- `promo`
- `holiday`
- `supplier_delay_days`

Додаткові колонки:
- `product_icon`
- `shelf_life_days`
- `supplier_name`
- `region`

Після імпорту CSV система перевіряє структуру, очищає дані, нормалізує числові поля, імпортує товари та продажі в SQLite і готує дані для прогнозування.

## Сторінки системи
- `Огляд` — короткий опис системи, KPI, практичне використання, графік прогнозу.
- `Дані` — структура CSV, імпорт даних, таблиця товарів і базова статистика.
- `Прогноз` — вибір товару, горизонт прогнозування, графік, висновок, фактори впливу.
- `Модель` — метрики MAE/RMSE/MAPE, порівняння моделей, топ факторів прогнозу.
- `Про систему` — мета, об’єкт, предмет, архітектура, SQLite, доступ, практична цінність.

## Метрики
- `MAE` — середня абсолютна помилка в одиницях товару.
- `RMSE` — метрика, чутлива до великих помилок.
- `MAPE` — середня відносна похибка у відсотках.

Менші значення метрик означають точніший прогноз. Основною моделлю обрано `ExtraTreesRegressor`, оскільки вона показала найнижче значення MAPE серед протестованих алгоритмів.
