# Демонстраційний CSV-датасет

Файл `sales_sample.csv` є штучно згенерованим набором даних для дипломного прототипу. Він імітує історичні продажі товарів у ритейлі та містить сезонність, акції, святкові дні, випадкові коливання попиту і затримки постачальників.

## Поля CSV

- `date` — дата продажів;
- `product_id` — ідентифікатор товару;
- `product_name` — назва товару;
- `category` — категорія товару;
- `sales_quantity` — кількість проданих одиниць;
- `price` — ціна товару;
- `stock_quantity` — залишок товару після продажів;
- `promo` — ознака акції: 1 або 0;
- `holiday` — ознака святкового дня: 1 або 0;
- `supplier_delay_days` — затримка постачальника у днях.

Цей набір даних не містить персональних або комерційних даних і призначений тільки для демонстрації роботи системи.
