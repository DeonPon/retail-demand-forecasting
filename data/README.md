# Демонстраційний набір даних

Файл `sales_sample.csv` є реалістично згенерованим демонстраційним набором даних для дипломного прототипу системи прогнозування попиту.

## Характеристики набору
- 74 товари;
- 12 категорій ритейлу;
- близько 365 днів історії;
- акції, святкові дні та сезонність;
- плавна зміна цін без хаотичних стрибків;
- залежність продажів від попиту, ціни, залишку, дня тижня та затримки постачання.

## Категорії
- Бакалія
- Молочні продукти
- Кондитерські вироби
- Напої
- Побутова хімія
- Зоотовари
- Фрукти та овочі
- Заморожені продукти
- Товари для дому
- Гігієна
- Кава та чай
- Снеки

## Колонки CSV
### Обов’язкові
- `date` — дата продажу;
- `product_id` — ідентифікатор товару;
- `product_name` — назва товару;
- `category` — категорія;
- `sales_quantity` — кількість проданих одиниць;
- `price` — ціна товару;
- `stock_quantity` — залишок після продажу;
- `promo` — ознака акції (`0` або `1`);
- `holiday` — ознака святкового дня (`0` або `1`);
- `supplier_delay_days` — затримка постачальника в днях.

### Додаткові
- `product_icon` — піктограма товару або категорії;
- `base_demand` — базовий попит товару;
- `seasonality_type` — тип сезонності;
- `shelf_life_days` — термін придатності;
- `supplier_name` — назва постачальника;
- `region` — регіон поставки.

## Призначення
Цей набір не містить персональних або комерційно чутливих даних і використовується лише для демонстрації роботи дипломного програмного прототипу.
