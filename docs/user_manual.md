# Коротка інструкція користувача

## 1. Запуск системи
1. Встановіть залежності з `requirements.txt`.
2. Запустіть застосунок командою:

```bash
py app/app.py
```

3. Відкрийте у браузері `http://127.0.0.1:5000`.

## 2. Імпорт CSV
1. Перейдіть на сторінку `Дані`.
2. Натисніть `Обрати CSV-файл`.
3. Виберіть файл з історичними продажами або завантажте приклад CSV.
4. Натисніть `Завантажити`.
5. Після імпорту система перевірить, очистить і збереже дані.

## 3. Перегляд даних
На сторінці `Дані` доступні:
- історичний період;
- кількість товарів;
- кількість категорій;
- кількість записів продажів;
- середній денний попит;
- структура CSV;
- таблиця товарів із базовою статистикою.

## 4. Побудова прогнозу
1. Перейдіть на сторінку `Прогноз`.
2. Оберіть товар.
3. Оберіть горизонт прогнозування: 7, 14 або 30 днів.
4. Натисніть `Побудувати прогноз`.
5. Перегляньте графік, короткий висновок, фактори впливу та таблицю прогнозу по днях.

## 5. Перегляд метрик
На сторінці `Модель` показано:
- обрану модель;
- MAE;
- RMSE;
- MAPE;
- кількість навчальних і тестових записів;
- порівняння моделей;
- топ факторів, що впливають на прогноз.

## 6. Перегляд опису системи
Сторінка `Про систему` містить мету, об’єкт, предмет, вхідні дані, алгоритм роботи, архітектуру, технології, SQLite, санкціонований доступ, практичну цінність і автора роботи.
