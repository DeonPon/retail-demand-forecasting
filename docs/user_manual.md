# Короткий посібник користувача

## 1. Вхід у систему
1. Відкрийте сторінку входу.
2. Введіть:
   - логін: `admin`
   - пароль: `admin123`
3. Натисніть кнопку «Увійти».

## 2. Dashboard
На dashboard доступні:
- KPI-картки;
- графік фактичних продажів і прогнозу;
- товари для закупівлі;
- товари з ризиком дефіциту;
- фактори, що впливають на прогноз;
- стан системи та останні імпорти.

## 3. Завантаження CSV
1. На dashboard оберіть CSV-файл.
2. Натисніть «Імпорт CSV».
3. Після успіху система покаже повідомлення з кількістю імпортованих товарів і рядків.

## 4. Перегляд прогнозу
1. Перейдіть на сторінку `Прогноз`.
2. Оберіть товар.
3. Оберіть горизонт: 7, 14 або 30 днів.
4. Перегляньте графік, таблицю прогнозу та пояснення.

## 5. Перегляд рекомендацій закупівель
1. Перейдіть на сторінку `Закупівлі`.
2. Перегляньте рекомендовану кількість замовлення.
3. Зверніть увагу на пріоритет:
   - високий;
   - середній;
   - низький.

## 6. Оцінка метрик
На сторінці `Метрики` доступні:
- MAE;
- RMSE;
- MAPE;
- найкраща модель;
- важливість ознак;
- порівняння моделей.

## 7. Як інтерпретувати фактори прогнозу
Система показує блок «Фактори впливу на прогноз», де пояснює:
- вплив акцій;
- вплив вихідних;
- низький або достатній залишок;
- зростання або спад продажів;
- ефект ціни;
- вплив затримки постачальника.
