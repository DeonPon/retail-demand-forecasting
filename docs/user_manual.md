# Короткий посібник користувача

## 1. Відкриття системи
1. Запустіть Flask-застосунок локально.
2. Відкрийте головну сторінку `http://127.0.0.1:5000`.
3. У демонстраційній версії інтерфейс відкривається одразу, щоб спростити показ системи під час захисту.

## 2. Dashboard
На dashboard доступні:
- KPI-картки;
- графік фактичних продажів і прогнозу;
- блок відповідності дипломному завданню;
- практична цінність прогнозування для ритейлу;
- фактори, що впливають на прогноз;
- інтерпретація прогнозу.

## 3. Завантаження CSV
1. Перейдіть на сторінку `Дані`.
2. Оберіть CSV-файл або завантажте демонстраційний приклад.
3. Натисніть «Завантажити».
4. Після успіху система покаже повідомлення з кількістю імпортованих товарів і рядків.

## 4. Перегляд прогнозу
1. Перейдіть на сторінку `Прогноз`.
2. Оберіть товар.
3. Оберіть горизонт: 7, 14 або 30 днів.
4. Перегляньте графік, таблицю прогнозу та пояснення.

## 5. Аналіз результату прогнозування
1. Перегляньте короткий висновок моделі.
2. Зверніть увагу на сумарний прогнозований попит, середній попит на день і тип динаміки.
3. Використайте таблицю прогнозу для аналізу очікуваних значень по днях.

## 6. Оцінка метрик
На сторінці `Метрики` доступні:
- MAE;
- RMSE;
- MAPE;
- обрана модель;
- важливість ознак;
- порівняння моделей.

## 7. Як інтерпретувати фактори прогнозу
Система показує блок «Фактори впливу на прогноз», де пояснює:
- вплив акцій;
- вплив вихідних;
- зростання або спад продажів;
- ефект ціни;
- вплив сезонності та календарних ознак.
