# План скріншотів для дипломної роботи та презентації

| Скріншот | Що показати | Підпис для пояснювальної записки |
| --- | --- | --- |
| Головна сторінка | Hero, KPI, практичне використання, приклад прогнозу. | Головна сторінка інтелектуальної системи прогнозування попиту. |
| Структура даних | Сторінка `Дані`, KPI датасету, блок структури CSV. | Структура вхідного набору даних для навчання моделі прогнозування. |
| Імпорт CSV | Блок імпорту CSV на сторінці `Дані`. | Завантаження CSV-файлу з історичними записами продажів. |
| Таблиця товарів | Таблиця з товаром, категорією, ціною, середнім попитом і періодом. | Базова статистика продажів товарів у наборі даних. |
| Прогноз попиту | Сторінка `Прогноз` з вибором товару і горизонту. | Побудова прогнозу попиту для вибраного товару. |
| Графік прогнозу | Синя історична лінія, вертикальна межа, зелений пунктир прогнозу. | Графік історичних продажів і прогнозу майбутнього попиту. |
| Короткий висновок | Блок із сумарним прогнозом, середнім попитом і типом динаміки. | Текстова інтерпретація прогнозу для користувача системи. |
| Фактори впливу | Блок факторів на сторінці `Прогноз`. | Основні фактори, які вплинули на сформований прогноз. |
| Оцінка якості моделі | KPI MAE, RMSE, MAPE на сторінці `Модель`. | Метрики оцінки точності моделі прогнозування. |
| Порівняння моделей | Таблиця RandomForestRegressor, GradientBoostingRegressor, ExtraTreesRegressor. | Порівняння моделей машинного навчання за метриками якості. |
| Топ факторів прогнозу | Графік або список важливих ознак. | Важливість ознак, використаних моделлю під час прогнозування. |
| Опис системи | Сторінка `Про систему`. | Опис мети, об’єкта, предмета та практичної цінності системи. |
| Архітектура | Flow CSV → Обробка → Ознаки → ML-модель → API → Web. | Узагальнена архітектура програмної системи. |
| Структура бази даних | `docs/database_schema.sql` або ER-схема. | Структура SQLite-бази даних дипломного прототипу. |
