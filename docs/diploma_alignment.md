# Відповідність дипломному завданню

## Офіційна тема
«Розробка інтелектуальної системи прогнозування попиту на товари для автоматизації процесів ритейлу».

## Мета роботи
Розробити інтелектуальну систему, яка на основі історичних даних продажів прогнозує попит на товари ритейлу.

## Об’єкт дослідження
Процес прогнозування попиту на товари у сфері роздрібної торгівлі.

## Предмет дослідження
Методи машинного навчання, структури даних, алгоритми обробки інформації та програмна реалізація системи прогнозування.

## Вихідні дані
Система працює з CSV-набором історичних продажів. Кожен запис містить дату продажу, товар, категорію, ціну, кількість проданих одиниць, календарні ознаки та допоміжні характеристики товару. Дані імпортуються у SQLite і використовуються для навчання та перевірки моделей прогнозування.

## Що реалізовано в програмі
- імпорт історичних продажів з CSV;
- перевірка, очищення та підготовка даних;
- збереження товарів, продажів та історії імпорту у SQLite;
- формування ознак для ML-моделі;
- навчання і порівняння моделей RandomForestRegressor, GradientBoostingRegressor та ExtraTreesRegressor;
- вибір основної моделі за MAPE;
- прогнозування попиту на 7, 14 або 30 днів;
- оцінка точності за MAE, RMSE і MAPE;
- пояснення факторів, які впливають на прогноз;
- web-інтерфейс для перегляду даних, прогнозу, якості моделі та опису системи;
- відкритий демонстраційний доступ для захисту з можливістю подальшого додавання авторизації.

## Відповідність сторінок частинам завдання
| Сторінка | Що демонструє |
| --- | --- |
| Огляд | Загальну ідею системи, KPI, приклад прогнозу, відповідність дипломному завданню та практичну цінність для ритейлу. |
| Дані | Структуру вхідного набору даних, CSV-імпорт, базову статистику продажів і підготовку даних для моделі. |
| Прогноз | Побудову прогнозу майбутнього попиту, графік історії та прогнозу, тип динаміки і фактори впливу. |
| Модель | Порівняння алгоритмів, вибір ExtraTreesRegressor, метрики MAE, RMSE, MAPE та топ ознак прогнозування. |
| Про систему | Мету, об’єкт, предмет, архітектуру, SQLite, санкціонований доступ, технології та практичну цінність. |
| /health та API | Технічну працездатність backend-рівня і можливість інтеграції прогнозу через HTTP endpoints. |

## Рекомендовані скріншоти для дипломної роботи
- головна сторінка системи;
- сторінка набору даних;
- імпорт CSV;
- сторінка прогнозу;
- графік історичних продажів і прогнозу;
- сторінка оцінки моделі;
- порівняння моделей;
- сторінка опису системи;
- архітектура системи;
- структура бази даних або SQL-схема.
