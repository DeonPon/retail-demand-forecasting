# Відповідність кваліфікаційній бакалаврській роботі

## Тема роботи
«Розробка інтелектуальної системи прогнозування попиту на товари для автоматизації процесів ритейлу».

## Мета
Розробити програмну систему, яка на основі історичних продажів товарів формує прогноз майбутнього попиту, оцінює якість моделі та надає користувачу зрозумілий web-інтерфейс для аналізу результатів.

## Об’єкт дослідження
Процес прогнозування попиту на товари у сфері роздрібної торгівлі.

## Предмет дослідження
Методи машинного навчання, структури даних, алгоритми обробки інформації та програмна реалізація системи прогнозування попиту.

## Практична цінність
Система може використовуватись як демонстраційний інструмент для аналізу історичних продажів, оцінки майбутнього попиту, виявлення динаміки продажів і підтримки управлінських рішень у ритейлі. Результати прогнозування можуть бути корисними для планування запасів, маркетингових активностей, оцінки сезонності та оптимізації операцій.

## Відповідність реалізованої системи завданню
- Прогнозування попиту реалізовано через ML-модуль і сторінку `Прогноз`.
- Автоматизація процесів ритейлу показана через імпорт CSV, обробку даних, побудову прогнозу та оцінку точності.
- Структури даних описані через CSV, SQLite-таблиці та сторінку `Дані`.
- Алгоритми реалізовані у preprocessing, feature engineering, навчанні моделей і покроковій генерації прогнозу.
- База даних SQLite використовується для локального збереження товарів, продажів, імпортів, прогнозів і метрик.
- Захист і санкціонований доступ описано як архітектурну можливість розширення системи авторизацією та ролями.
- Питання програмної інженерії відображені в модульній структурі проєкту, тестах, API та документації.

## Відповідність пунктів завдання частинам системи
| Пункт завдання | Частина системи |
| --- | --- |
| Розробити модель прогнозування | `src/train_model.py`, `src/predict.py`, сторінка `Модель`. |
| Розробити структури необхідних даних | CSV-структура, `data/README.md`, сторінка `Дані`. |
| Розробити алгоритми | Preprocessing, feature engineering, model selection, forecast generation. |
| Структура бази даних | `src/database.py`, `docs/database_schema.sql`, `docs/database_description.md`. |
| Автоматизація процесів ритейлу | CSV import, прогноз, метрики, web-інтерфейс. |
| Управління запасами | Прогноз попиту як основа для планування запасів. |
| Ціноутворення | Поле `price` і похідні ознаки ціни в моделі. |
| Маркетинг | Поля `promo`, `holiday`, сезонність і календарні ознаки. |
| Логістика | Поле `supplier_delay_days` як допоміжна характеристика. |
| Графічні матеріали | Графік прогнозу, таблиці даних, метрики, архітектура системи. |
