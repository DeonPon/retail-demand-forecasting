# Звіт про тестування

## Що тестувалося
- локальний запуск застосунку;
- сторінки `Огляд`, `Дані`, `Прогноз`, `Модель`, `Про систему`;
- API endpoints;
- імпорт CSV;
- перенавчання моделі;
- модуль прогнозування попиту.

## Автоматичні тести
У проєкті наявні:
- `tests/test_api.py`
- `tests/test_model.py`
- `tests/test_data_import.py`
- `tests/test_recommendations.py`

## Результати метрик
- найкраща модель: `ExtraTreesRegressor`
- MAE: `2.005`
- RMSE: `3.194`
- MAPE: `12.793%`

## Приклади тестових сценаріїв
1. Відкриття головної сторінки без обов’язкового входу.
2. Перехід на сторінку даних із фільтром по категорії.
3. Відкриття прогнозу по конкретному товару на 14 днів.
4. Перегляд метрик і порівняння моделей.
5. Імпорт тестового CSV у базу даних.
6. Повторне навчання моделі після оновлення даних.

## Висновок
Система працездатна як дипломний програмний прототип: сторінки відкриваються, API відповідає коректно, модель навчається, прогноз формується, метрики відображаються, а імпорт CSV обробляється без критичних помилок.
