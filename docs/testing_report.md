# Звіт про тестування

## Що тестувалося

- запуск генерації CSV;
- навчання ML-моделі;
- збереження `models/demand_model.joblib`;
- збереження `models/metrics.json`;
- авторизація;
- dashboard;
- API endpoint-и;
- рекомендації закупівель;
- SQLite-ініціалізація.

## API endpoints

Перевірені endpoint-и:

- `GET /api/products`;
- `GET /api/forecast/1?days=14`;
- `GET /api/recommendation/1?days=14`;
- `GET /api/metrics`;
- `GET /api/system-info`;
- `POST /api/retrain`.

## Метрики

Після навчання модель зберігає MAE, RMSE і MAPE у `models/metrics.json`. Значення можуть змінюватися після оновлення датасету.

## Приклади тестових сценаріїв

1. Користувач входить як `admin`.
2. Відкриває dashboard.
3. Обирає товар.
4. Переглядає прогноз.
5. Переглядає рекомендацію закупівлі.
6. Завантажує новий CSV.
7. Система перенавчає модель.

## Висновок

Прототип покриває ключові вимоги дипломного завдання: прогнозування, автоматизація рекомендацій, структура БД, санкціонований доступ, API та презентабельний інтерфейс.
