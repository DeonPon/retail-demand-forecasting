## Приклади тестових сценаріїв
1. Вхід під демо-користувачем і відкриття dashboard.
2. Перехід на сторінку товарів із фільтром по категорії.
3. Відкриття прогнозу по конкретному товару на 14 днів.
4. Перегляд рекомендацій закупівель.
5. Імпорт тестового CSV у базу даних.
6. Повторне навчання моделі після оновлення даних.

## Висновок
Система працездатна як дипломний програмний прототип: сторінки відкриваються, API відповідає коректно, модель навчається, прогноз формується, рекомендації закупівель розраховуються, а імпорт CSV обробляється без критичних помилок.
