Про систему

Інтелектуальна система прогнозування попиту на товари

Цей розділ описує призначення, предметну область, архітектуру та практичну цінність розробленої системи.

Система створена як програмна реалізація до кваліфікаційної роботи. Вона охоплює повний цикл прогнозування попиту: від завантаження історичних продажів до побудови прогнозу та пояснення результатів.

Мета роботи

Розробити інтелектуальну систему, яка на основі історичних даних продажів прогнозує попит на товари ритейлу.

Об’єкт дослідження

Процес прогнозування попиту на товари у сфері роздрібної торгівлі.

Предмет дослідження

Методи машинного навчання, структури даних, алгоритми обробки інформації та програмна реалізація системи прогнозування.

Вхідні дані

У системі використовуються історичні записи продажів: дата, товар, категорія, ціна, кількість проданих одиниць, календарні ознаки, акційні періоди та допоміжні характеристики товару.

Алгоритм роботи

  1. Завантаження та перевірка CSV-даних.
  2. Очищення, нормалізація і формування ознак.
  3. Навчання кількох моделей машинного навчання.
  4. Вибір найкращої моделі за MAPE.
  5. Побудова прогнозу для вибраного товару та періоду.

Використані технології

  • Python, Flask, Jinja2.
  • pandas для обробки табличних даних.
  • scikit-learn для навчання моделей прогнозування.
  • SQLite для локального зберігання даних.
  • HTML, CSS і JavaScript для інтерфейсу демонстраційної системи.

База даних

Для локального збереження даних використовується SQLite. У базі зберігаються товари, історичні продажі, результати імпорту та допоміжна інформація для роботи системи.

Санкціонований доступ

У демонстраційній версії доступ до інтерфейсу відкритий для зручності захисту. Архітектура системи дозволяє надалі додати авторизацію користувачів і розмежування ролей.

Практична цінність

Система може використовуватись як демонстраційний інструмент для аналізу продажів, оцінки очікуваного попиту та підтримки управлінських рішень.
